# CCMM 점심 룰렛

여의도 CCMM빌딩(여의공원로 101) 주변, **여의도공원을 건너지 않고 국회의사당역까지** 범위의
점심 후보를 룰렛으로 뽑고, 다녀온 뒤 **KMAC 별점**을 남기는 정적 웹페이지.
서버 없이 `index.html` + `data.js` + `reviews.js` 세 파일로 동작한다.

- 페이지: https://ukiahptc.github.io/ccmm-lunch-roulette/
- 로컬에서 보려면 `index.html` 을 브라우저로 열면 된다.

## 화면 구성

| 구역 | 하는 일 |
|---|---|
| 룰렛 | 필터를 통과한 후보만 원판에 올라간다. 결과는 팝업으로 뜬다. |
| 필터 | 음식 분류 · 구역 · KMAC 평가 조건(평균 별점, 평가 없는 곳 포함 여부, 재방문 의사) · 기타(최근 5회 제외 등). 아래 요약줄에 현재 조건과 후보 수가 나온다. |
| 후보지 목록 | 전체 후보 표. 체크를 끄면 룰렛에서 빠진다. "평가" 버튼으로 KMAC 별점 입력. 검색·정렬 가능. |
| 결과 팝업 | 당첨 식당 정보, 네이버지도·카카오맵 링크, KMAC 평가하기, 다시 돌리기, 오늘은 빼고 다시. |

## KMAC 별점

- 항목: 맛 · 청결 · 친절도 (각 5점 만점, 0.5 단위), 재방문 의사 Y/N, 비고, 닉네임.
- 식당별로 여러 명이 남길 수 있고, 표와 팝업에는 세 항목 평균과 재방문 비율, 평가 인원이 보인다.
- 저장 위치는 두 곳이다.
  - **내 브라우저(localStorage)**: 평가를 저장하면 우선 여기에 쌓인다. 다른 사람에게는 안 보인다.
  - **`reviews.js`(공유)**: 여기에 들어 있는 평가는 모두에게 보인다.
- 팀과 공유하는 방법: 후보지 목록의 **평가 내보내기** → 받은 JSON 파일 내용을 `reviews.js` 의 `window.REVIEWS = [ ... ]` 대괄호 안에 붙여 넣고 커밋. 배열 안에 여러 사람 것을 이어 붙여도 된다(`rid` 가 다르면 모두 유지).
- **평가 가져오기**: 다른 사람이 내보낸 JSON 을 내 브라우저에 합친다(커밋 없이 잠깐 합쳐 볼 때).

## 후보 목록 수정 (`data.js`)

식당 한 곳이 한 줄이다. GitHub 웹에서 연필 아이콘으로 열어 고치고 Commit changes 하면 1~2분 뒤 반영된다.

```js
{"id":"jungin","name":"정인면옥","cat":"한식","menu":"평양냉면·만두","price":"1.5만~1.7만",
 "addr":"국회대로76길 10 1층","bldg":"기독교침례회총회빌딩","zone":"alley","src":"미쉐린 빕구르망","q":""},
```

- 삭제: 그 줄을 통째로 지운다.
- 룰렛에서만 빼고 목록엔 남기기: 줄 끝 `"q":""` 뒤에 `,"closed":true`.
- 추가: 아무 줄이나 복사해서 `id`(영문, 중복 금지)·이름·분류·주소·구역을 바꾼다.
- `cat`: 한식 · 일식 · 중식 · 양식 · 아시안 · 분식·기타
- `zone`: `ccmm` CCMM빌딩 안 · `bank` 은행로 · `alley` 국회대로 골목 · `main` 국회대로 본선 · `station` 국회의사당역 출구
- `src`: 비고(휴무일, 참고 정보). 화면에 그대로 표시.
- `q`: 지도 검색어. 비우면 `상호 + 여의도`.

배포 반영은 커밋 후 보통 1~2분. 옛 화면이 보이면 Ctrl+F5 (맥 Cmd+Shift+R).
