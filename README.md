# CCMM 점심 룰렛

여의도 CCMM빌딩(여의공원로 101) 주변, **여의도공원을 건너지 않고 국회의사당역까지** 범위의
점심 후보를 룰렛으로 뽑고, 다녀온 뒤 **KMAC 별점**을 남기는 정적 웹페이지.
서버 없이 정적 파일로 동작하고, 평가 저장소로 구글 시트(Apps Script 웹앱)를 쓴다.

- 페이지: https://ukiahptc.github.io/ccmm-lunch-roulette/
- 로컬에서 보려면 `index.html` 을 브라우저로 열면 된다.

## 화면 구성

| 구역 | 하는 일 |
|---|---|
| 룰렛 | 필터를 통과한 후보만 원판에 올라간다. 결과는 팝업으로 뜬다. |
| 필터 | 음식 분류 · 구역 · KMAC 평가 조건(평균 별점, 평가 없는 곳 포함 여부, 재방문 의사) · 기타(최근 5회 제외 등). 아래 요약줄에 현재 조건과 후보 수가 나온다. |
| 후보지 목록 | 전체 후보 표. 체크를 끄면 룰렛에서 빠진다. "평가" 버튼으로 KMAC 별점 입력. 검색·정렬, 시트 새로고침. |
| 결과 팝업 | 당첨 식당 정보, 네이버지도·카카오맵 링크, KMAC 평가하기, 다시 돌리기, 오늘은 빼고 다시. |

## KMAC 별점

- 항목: 맛 · 청결 · 친절도 (각 5점 만점, 0.5 단위), 재방문 의사 Y/N, 비고, 닉네임.
- 식당별로 여러 명이 남길 수 있고, 표와 팝업에는 세 항목 평균과 재방문 비율, 평가 인원이 보인다.
- 삭제는 같은 닉네임으로 남긴 본인 평가만 가능하다.

### 저장 방식: 구글 시트 (권장)

`config.js` 에 Apps Script 웹앱 URL 이 들어 있으면 모든 평가가 구글 시트에 저장되고, 페이지를 여는 사람 모두에게 보인다.
전송이 실패하면 브라우저에 임시 보관했다가 다음 접속 때 자동으로 다시 보낸다.

설치 (1회, 약 5분):

1. 구글 드라이브에서 새 스프레드시트를 만든다. 이름은 자유 (예: `CCMM 점심 룰렛 평가`).
2. 시트 메뉴 **확장 프로그램 → Apps Script**.
3. 편집기에 기본으로 들어 있는 `function myFunction() {}` 를 모두 지우고, 이 저장소의 `apps-script/Code.gs` 내용을 통째로 붙여 넣은 뒤 저장(Ctrl+S).
4. 오른쪽 위 **배포 → 새 배포** → 왼쪽 톱니(유형 선택) → **웹 앱**.
   - 설명: 아무거나
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   → **배포** → 권한 승인 창에서 계정 선택 → "확인되지 않은 앱" 경고가 뜨면 **고급 → (프로젝트명)(으)로 이동 → 허용**.
5. 표시되는 **웹 앱 URL** (`https://script.google.com/macros/s/…/exec`) 을 복사해 `config.js` 의 `sheetApi` 값에 넣고 커밋.
6. 페이지를 새로고침하면 후보지 목록 제목 옆에 "구글 시트 연결됨" 이 뜬다.

시트에는 `reviews` 탭이 자동으로 생기고, 열은 `rid | id | who | taste | clean | kind | revisit | note | date | created_at | deleted` 순이다.
삭제한 평가는 행을 지우지 않고 `deleted` 열에 TRUE 로 표시한다. 시트에서 직접 행을 고치거나 지워도 된다.

Code.gs 를 수정한 뒤에는 **배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포** 를 해야 반영된다. URL 은 그대로다.

### 저장 방식: 로컬 모드 (시트 미설정 시)

`sheetApi` 가 비어 있으면 평가는 각자 브라우저(localStorage)에만 저장된다.
이때는 **평가 내보내기**로 받은 JSON 을 `reviews.js` 의 대괄호 안에 붙여 넣고 커밋하면 공유된다.

## 후보 목록 수정 (`data.js`)

식당 한 곳이 한 줄이다. GitHub 웹에서 연필 아이콘으로 열어 고치고 Commit changes 하면 1~2분 뒤 반영된다.

```js
{"id":"jungin","name":"정인면옥","cat":"한식","menu":"평양냉면·만두","price":"1.5만~1.7만",
 "addr":"국회대로76길 10 1층","bldg":"기독교침례회총회빌딩","zone":"alley","src":"미쉐린 빕구르망","q":""},
```

- 삭제: 그 줄을 통째로 지운다.
- 룰렛에서만 빼고 목록엔 남기기: 줄 끝 `"q":""` 뒤에 `,"closed":true`.
- 추가: 아무 줄이나 복사해서 `id`(영문, 중복 금지)·이름·분류·주소·구역을 바꾼다.
- `cat`: 한식 · 일식 · 중식 · 양식 · 아시안 · 분식·기타
- `zone`: `ccmm` CCMM빌딩 안 · `bank` 은행로 · `alley` 국회대로 골목 · `main` 국회대로 본선 · `station` 국회의사당역 출구
- `src`: 비고(휴무일, 참고 정보). 화면에 그대로 표시.
- `q`: 지도 검색어. 비우면 `상호 + 여의도`.

배포 반영은 커밋 후 보통 1~2분. 옛 화면이 보이면 Ctrl+F5 (맥 Cmd+Shift+R).
